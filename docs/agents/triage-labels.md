# Triage labels

Use these workflow labels as mutually understandable states:

| Label | Meaning | Exit condition |
|---|---|---|
| `needs-triage` | Scope, ownership, evidence, or dependencies have not been assessed. | The issue has acceptance evidence and a clear next owner. |
| `needs-info` | A named fact or decision blocks safe progress. | The missing evidence is recorded and the issue is re-triaged. |
| `ready-for-agent` | An agent can complete the issue from repository material and verified contracts. | Work begins, the contract changes, or human action becomes necessary. |
| `ready-for-human` | The next step requires a person, physical system, official confirmation, credential, or professional judgment. | Human evidence is attached and the issue is re-triaged. |
| `wontfix` | The team deliberately declines the issue. | Reopen only when the recorded premise materially changes. |

Keep GitHub's standard type labels when useful. These five labels describe workflow, not severity or component.
