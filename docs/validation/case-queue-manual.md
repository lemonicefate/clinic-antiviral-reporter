# 案件工作清單：人工操作驗收

適用 #8。2026-10-03 已搭建並完成自動驗證。此輪請測實際操作感受及畫面核對，
不必重做先前已通過的裝置配對步驟。

更新：依使用者要求，助理已自行操作並通過下列可客觀判定的步驟，包含鍵盤、
720／1080／1440px 與 125% 頁面縮放；不再要求使用者重做。下列流程保留供日後
重現或查錯使用，不代表原生 Windows DPI 或主觀操作舒適度已經人工驗收。

## 環境與開啟方式

本機驗收環境使用專案的正式 React build 與真實 HTTPS 中央 API；瀏覽器連接層
模擬 A 管理裝置、B 醫師裝置、C 未配對裝置，身分憑證僅留在測試程序記憶體。
這不是原生 Tauri、Windows 憑證保管或兩台實體電腦互連的驗收證據。

助理會在交付訊息提供本次可直接開啟的連結。若環境已關閉，於專案根目錄執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_acceptance.ps1
```

不必輸入 HIS 路徑、金鑰或病患資料。啟動器會開啟驗收首頁。測試資料保存在
`%LOCALAPPDATA%\ClinicReporterAcceptance\case-queue-v1`，與前次環境分開。
每次完整啟動建立新 run；首頁「停止／啟動測試中央」會保留同一 run 的歷史。
日期固定為本次首次建案日期與前一天；隔日重啟同一中央，逾期筆數可能增加，
不會將來源日期偷偷改為今天。所有數量都是 10 顆的固定合成樣本。

## 逐步操作與預期結果

1. **開啟醫師 B**：首頁點「B：醫師」。操作身分填 `SYN-DR-A`，設定方式保持
   「使用已配對裝置」，按「連線」。應看到 3 案、1 案跨日未完成；`SYN-0002`
   排在前面。`SYN-0001` 有兩案，各有不同醫令，且顯示同日多筆提醒。
2. **醫師篩選**：選 `SYN-DR-B` 並按「查詢清單」。應只剩 `SYN-0003` 一案。
   再選「全部醫師（協助處理）」並查詢，應有 4 案。
3. **完整病歷號搜尋**：將醫師選回 `SYN-DR-B`，病歷號填 `SYN-0001` 並查詢。
   應跨醫師找到兩案。改填 `0001` 並查詢，應為零案。清空病歷號再查詢，應恢復
   所選醫師的一案，不能把「零案」或讀取失敗當成原先資料消失。
4. **明確核對**：搜尋 `SYN-0001`。未點選前不應自動打開任何案件。點其中一筆
   「核對此案」，焦點應移至「核對案件」。核對姓名、病歷號、出生日期、給藥
   日期、醫師、來源醫令；來源量與回報量應皆為 10 顆。另一筆醫令有獨立詳情，
   不應合併。展開「原始合成來源」，應有一版且保留原始欄位。理由填寫尚屬下一步。
5. **刷新去重**：首頁開 A 管理者，操作身分同填 `SYN-DR-A`。登入後點「案件
   工作清單」，選全部醫師並查詢，再按「刷新合成來源」。應顯示新增 0、未變 4，
   總數仍為 4。B 醫師不應出現刷新按鈕。
6. **停機清除及恢復**：B 保持案件詳情開啟；首頁按「停止測試中央」。約十秒內
   B 應返回連線頁，清單、姓名、案件詳情消失，並提示紙本流程。首頁按「啟動
   測試中央」後，B 手動重新連線。應重新從中央取得三案，沒有多建案件。
7. **診間使用感受**：用 Tab／Enter 搜尋與選案，在平常使用的視窗寬度與縮放比
   檢查文字、數量、重複警示是否容易辨認，焦點是否清楚，是否容易點錯醫令。

## 結束與回報

首頁按「結束整個測試環境」才會停止背景程序；單純關閉分頁不會停止。
不需刪除測試資料或回復資料庫。

回報格式：`版本／測試日期；步驟 1–7：通過或未通過；未通過步驟：操作、預期、實際結果`。
若全數正常，回覆「案件清單步驟 1–7 全通過」即可。不要貼金鑰或真實病人畫面。

## 助理已自動測的部分

API：去重與原結果重送、重啟、同日獨立醫令、原始快照、完整病歷號、跨醫師查詢、
能力／撤銷拒絕、刷新版本衝突、production 與未啟用模式拒絕合成匯入。
SQLite v1/v2 升至 v3 保留操作歷史；新版資料庫拒絕啟動而不修改檔案。
前端：明確選案、焦點、斷線清除，以及原裝置管理回歸測試。
真實 HTTPS 瀏覽器整合：醫師篩選、核對、刷新、停機、恢復、720px 無頁面溢出、
localStorage/sessionStorage 不留病人內容。Rust：憑證保管與編碼查詢路徑驗證。

重現整合測試（先啟動環境）：於 `client` 執行 `node e2e-real/case-queue.cjs`。
自動測試會暫停再啟動此測試中央，請勿與人工測試同時執行。
